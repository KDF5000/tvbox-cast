## 2.0.1-beta.1 · 首次公开测试版

发布日期：2026-11-08。

- 发布独立 DLNA 接收器、电视首页、遥控器控制和外部字幕支持。
- 真实播放状态和进度回传，支持标准 GENA 状态订阅。
- 明确区分 Wi-Fi 连接与投屏服务就绪，加入设备命名、设置和默认桌面引导。
- 网络变化后的端点重建与视频打开超时提示。
- 公共构建移除仅用于旧华为系统的兼容服务，使用独立长期发布签名。
- 加入原创投屏图标和电视应用横幅。

测试：152 项本地检查通过，独立 DLNA 在 EC6108V9_8G / Android 4.4.2 完成基础运行实测。
公开签名构建尚未在该设备覆盖安装；签名不同，不能覆盖私人调试版。
其他设备、手机客户端、长时间运行、冷启动与唤醒仍需扩大验证。

已知限制见 README 和 FAQ。测试版不包含独立 AirPlay / Google Cast / 屏幕镜像 / DRM 支持。
