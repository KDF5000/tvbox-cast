# 安装与使用

## 先确认是否适合

这是 Android 电视 / 盒子上的接收软件，不是手机 App。
最低 Android 4.4，已有基础实测仅限华为悦盒 EC6108V9_8G；不能保证任意设备。
需要标准 DLNA 发送端，不能把 AirPlay、Google Cast 或平台官方投屏当作同一协议。

## 安装

1. 在 Releases 下载 `.apk`。需要校验时对照同版本的 `SHA256SUMS.txt`。
2. 将 APK 通过 U 盘或设备支持的文件传输方式交给电视；按系统提示仅允许可信安装来源。
3. 打开“大屏投屏”，连接家庭网络，等待“独立 DLNA 已就绪”。
4. 在支持 DLNA 的手机播放器中选择首页的名称，例如“大屏投屏 · XXXX”。
5. 初次使用建议先测普通短 MP4，再测试你常用的 App / 视频。

不需要 Root，不需要禁用任何系统应用，也不需要向他人开放 ADB / Telnet。
保留原桌面、网络设置及恢复路径。不要在正在观看时升级应用。

## 遥控器

- 播放页：左右短按跳转 10 秒，长按连续跳转；确定播放 / 暂停；上 / 下 / 菜单显示播放条；返回退出。
- 首页：菜单 / 确定打开设置，可修改设备名、连接网络、开关服务和查看诊断。
- 直播和未知时长视频不保证可以跳转；字幕轨与解码能力依赖设备。

## 开机进入投屏页面

在应用菜单选择“设为默认桌面”，在系统允许的情况下选择“大屏投屏”为默认 HOME。
默认选择由用户确认；有些运营商盒子和电视固件不允许替换桌面。
开机广播只初始化接收服务，不在后台强制弹页面。首次安装后先手动打开一次。
冷启动、待机唤醒与后台运行效果要在自己的设备上验证。

## 升级与卸载

公开版本采用独立发布签名。此前私下安装的调试版不能覆盖升级，需先卸载再安装；
卸载会清除设备名等本地配置，必要时先切回原桌面并确认系统设置仍可用。
同签名的后续公开版正常覆盖升级即可。

恢复原桌面时到系统默认应用 / 桌面设置选择原应用，再卸载本软件。
没有要求删除系统 APK。拒绝可选 Wi-Fi 名称权限不会阻止独立 DLNA 工作。
