把手机接上大屏。

最低安装要求 Android 4.4。
这是接收端软件，请安装在电视或盒子上，
不是安装在手机上。

  1. 1

    安装到电视

    下载 APK，通过 U 盘或设备支持的文件管理器侧载。首次安装后，手动打开“大屏投屏”。

  2. 2

    连接家庭网络

    等待“独立 DLNA 已就绪”。手机与盒子可分别连接 2.4G 和 5G，前提是网络互通。

  3. 3

    选择首页的名称

    在支持 DLNA 的播放器里选择“大屏投屏 · XXXX”。菜单键可修改设备名和查看诊断。

想开机直接进入投屏页？

菜单里选择“设为默认桌面”，再由系统和你确认。部分厂商不允许替换桌面，请保留原桌面与设置入口。

05 / 常见问题

说清楚，
再开始。

没解决？反馈问题

任何 App、任何网页视频都能投吗？

不能保证。当前支持标准 DLNA，不包含平台官方专用投屏、AirPlay、Google Cast、屏幕镜像或 DRM 解密。B 站和 YouTube 的某些入口可能不显示标准 DLNA 设备；网页链接也不是直接视频地址。

一定要连接相同的无线网络吗？

不要求名称相同，2.4GHz、5GHz 和网线可以互通。需要两端位于同一可互通 IPv4 子网，路由器允许设备互访与多播发现。检查访客网络、客户端隔离和 VPN。

为什么搜索不到，或连接后不能播放？

先确认首页“独立 DLNA 已就绪”，发送端支持 DLNA，iPhone 允许 App 访问本地网络。连接成功仍可能遇到源站鉴权、视频编码、TLS 或设备播放器限制，建议先用普通短 MP4 测试。

需要 Root、刷机或删除原应用吗？

不需要。安装不禁用原桌面或系统服务。能否设为默认桌面由设备厂商和用户决定。请保留系统设置与恢复入口，也不要向他人开放 ADB / Telnet。

会收集数据吗？权限是做什么的？

应用没有账号、广告、统计 SDK 或自建云端中转。网络、多播和唤醒权限用于接收服务；可选位置权限只满足部分系统读取无线网络名称的要求，不调用定位接口。在线视频仍需访问源站。

这是开源软件吗？能在公共网络用吗？

应用源码暂未开源，仓库提供 APK、文档和反馈，不代表授予再分发或商用授权。本版没有 PIN / 配对，同一子网设备可以控制播放，只建议可信家庭网络使用，勿将端口映射到公网。
