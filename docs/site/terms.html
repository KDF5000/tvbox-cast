使用条款

本页适用于大屏投屏公开测试版。下载前请了解以下使用范围和限制。

测试版与兼容范围

应用是 Android 电视或盒子的标准 DLNA 视频接收端，不提供内容库。最低安装要求为 Android 4.4，目前只完成一款华为悦盒的基础实测。其他设备、发送端、开机和长期运行仍需扩大验证，不能承诺所有视频都能播放。

本版没有独立 AirPlay、Google Cast、屏幕镜像、网页视频提取或 DRM 解密功能。请先用普通短 MP4 测试，并保留原桌面、系统设置和恢复入口。

家庭网络与内容

请仅在可信家庭网络使用。本版没有 PIN 或配对授权，同一子网设备可以控制播放。不要将端口映射到公网，不要向他人开放 ADB 或 Telnet。

请仅播放你有权访问和使用的内容。视频、字幕和源站的服务条件由相应提供方决定，本应用不提供或授权这些内容。

安装、迁移与备份

安装前请保存需要保留的配置。公开版与私人调试版签名不同，不能直接覆盖；卸载后重新安装可能丢失本地配置。后续同签名公开版本可以正常升级。

软件与分发

应用源码暂未开源。公开仓库提供下载、文档和问题反馈，不代表授予再分发或商用授权。网站中的第三方字体和图标按随附许可证使用。

隐私与反馈

官网不主动使用广告、统计脚本、账号或追踪 Cookie。托管平台可能处理基础访问日志。下载与反馈前往 GitHub，其数据处理遵循 GitHub 的政策。

完整隐私和权限说明。反馈时请不要上传密码、鉴权视频链接或完整设备备份。
