# 隐私和权限说明

更新日期：2026-11-08。适用于大屏投屏公开测试版。

## 数据处理

应用接收局域网发送端给出的媒体 URL、标题和字幕 URL，在设备上处理并播放。
媒体 URL / 元数据会通过标准 DLNA 查询和事件通知返回给同一子网的控制端。
应用配置保存设备 UUID、设备名和服务开关；清除应用数据会重置配置。

没有接入账号、广告、统计 / 分析 SDK 或自建云端中转。
在线媒体和字幕需要设备访问其源站；这些服务和设备系统有各自的网络行为与隐私政策。
应用日志不打印完整媒体 / 字幕 URL 和鉴权参数，但公开反馈前仍请检查截图和日志中的个人信息。

## 权限用途

| 权限 | 用途 |
| --- | --- |
| 网络、网络状态、Wi-Fi 状态 | 接收投屏、读取网络连接状态 |
| Wi-Fi 多播 | 标准 SSDP 设备发现 |
| 唤醒锁、前台服务 | 服务开启且网络就绪时保持接收，可在菜单关闭 |
| 开机完成广播 | 初始化接收服务，不强制后台弹出页面 |
| 可选位置权限 | 满足部分 Android 版本读取已连接 Wi-Fi 名称的要求；不调用定位接口 |

不要求通讯录、麦克风、摄像头或相册权限。拒绝可选位置权限不影响独立 DLNA 接收。

## 网络安全边界

当前没有 PIN 或配对授权，同一 IPv4 子网的设备可以设置媒体并控制播放。
仅在可信家庭网络使用，不要映射端口到公网，也不要将设备 ADB / Telnet 暴露给他人。
HTTP 控制与视频传输不保证端到端加密，源站是否使用 HTTPS 由源地址决定。
请求 / 元数据 / 字幕有大小限制，XML 禁止 DTD / 实体，事件回调限制为请求者自身地址。
公开版不包含旧华为兼容 Binder 入口。

## 官网

官网不主动使用统计脚本、广告、账号或追踪 Cookie。托管平台仍可能处理基础访问日志。
下载和问题反馈链接前往 GitHub，其数据处理遵循 GitHub 的政策。

## 联系与反馈

通过仓库 Issues 提交问题。请勿提供密码、Wi-Fi 密码、鉴权视频链接或完整设备备份。
