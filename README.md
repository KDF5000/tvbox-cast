# 大屏投屏

开源、轻量的 Android DLNA 视频接收器。打开电视，等待投屏，把时间留给观看。

**当前为小范围公开测试版，不是保证所有电视、手机 App 都兼容的正式产品。**

[官网](https://tvbox-cast.kongdefei8813.chatgpt.site/) · [下载 APK](https://github.com/KDF5000/tvbox-cast/releases/tag/v2.0.1-beta.1) · [应用源码](cast-launcher/src/local/tvbox/castlauncher) · [构建说明](docs/BUILD.md) · [安装与使用](docs/INSTALL.md) · [反馈问题](https://github.com/KDF5000/tvbox-cast/issues/new/choose)

## 能做什么

- 独立标准 DLNA 视频接收，不依赖华为系统服务，不需要 Root。
- 播放 / 暂停 / 进度查询与控制，遥控器左右短按跳转 10 秒、长按连续跳转。
- 外部 SRT / WebVTT 字幕透明显示；内嵌字幕依赖设备播放器支持。
- 显示 Wi-Fi 名称与接收服务状态，可修改投屏设备名称。
- 网络变化后重建接收端点，提供服务开关、诊断与系统设置入口。
- 设备允许时，由用户选择为默认桌面，系统进入桌面后显示投屏首页。

应用没有内置广告、会员或账号登录，也不提供视频内容库。

## 使用条件和边界

最低安装要求 Android 4.4 / API 19。基础实测设备：华为悦盒 EC6108V9_8G，Android 4.4.2。
最低版本要求不是跨设备兼容承诺；其他型号、现代系统和开机 / 唤醒行为仍需实测。

手机发送端必须支持标准 DLNA；视频地址需能被盒子直接读取和解码。
两端需位于同一可互通 IPv4 子网，路由器允许设备互访和多播发现。
可以分别连接 2.4GHz 与 5GHz，不要求 Wi-Fi 名称相同。

**不包含独立 AirPlay、Google Cast、屏幕镜像、视频网站官方专用投屏或 DRM 解密。**
不能承诺 B 站、YouTube 等 App 一定搜索到设备，网页能播放也不等于盒子能直接播放。
保持投屏首页 / 播放页在前台；未知时长直播不支持常规快进快退。

当前没有 PIN / 配对验证，同一子网用户可以控制播放。只在可信家庭网络使用，勿映射端口到公网。

## 安装和升级

从 Releases 下载 APK，按设备支持的方式通过 U 盘 / 文件管理器侧载，然后手动打开应用。
安装无需禁用原桌面和系统服务，无需开放 ADB / Telnet。

公开版使用独立发布签名；之前私人调试版不能直接覆盖安装，需要先卸载调试版再安装公开版，
设备名和默认桌面选择等配置可能需要重新设置。当前悦盒的私人调试版不会被本次发布自动更新。
后续同签名公开版可按版本号升级。

## 源码与开发

Android 应用源码位于 [`cast-launcher`](cast-launcher)，包含独立 DLNA 接收器、播放器、界面、资源和协议测试。
代码基于当前 `2.0.1-beta.1` 公开版本，不包含已经从公开 APK 移除的旧华为兼容入口。
预览和测试中的设备地址已换成文档示例地址。

安装 JDK 17 后可运行纯 Java 测试，无需 Android SDK、电视或 ADB：

```sh
sh cast-launcher/test.sh
```

构建 APK 需要 Node.js 18+、JDK 17、Android SDK 和 `zip`。设置 `ANDROID_SDK_ROOT` 后运行：

```sh
node cast-launcher/build.mjs
```

详见 [构建和架构说明](docs/BUILD.md) 与 [贡献指南](CONTRIBUTING.md)。
本地构建使用本机生成的调试签名，不能直接覆盖官方签名 APK；构建、测试和预览均不会操作电视。
